# Red Teaming and OT Security Resource Hub

A curated learning hub for red teaming, OT/ICS security, physical security crossover, and ethical security research. This site collects publicly available, reputable resources to help beginners and intermediate practitioners explore these fields responsibly.

All content here is oriented toward **legal, authorized, and ethical** security research. Nothing on this site constitutes operational attack guidance.

## Ethics and Disclaimer

The resources collected here are intended exclusively for **educational use, authorized research, and legal security work**. Key principles to keep in mind:

- Always obtain written authorization before testing any system you do not own.
- OT/ICS environments can have life-safety implications. Lab environments and simulation tools exist for a reason — use them.
- Physical security research should respect privacy laws and property rights.
- Many tools listed here have both offensive and defensive applications. Use them responsibly and within the law.
- When in doubt, consult the relevant legal frameworks for your jurisdiction (e.g., the Computer Fraud and Abuse Act in the US).

This site is a personal project and does not represent any organization or institution. Links are provided for educational reference only.
